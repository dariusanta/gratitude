# Gratitude

A small phone web app for keeping track of moments of gratitude.

- Write a moment → it's saved with the date and time
- Moments are listed newest first, grouped by day (Today, Yesterday, …)
- Edit (original time is kept, marked "edited") or delete moments
- Daily reminder via a repeating event in your phone's calendar
- Export / import a JSON backup
- Follows your phone's light/dark mode, works offline

Entries are stored only on your phone (browser `localStorage`). Nothing is sent anywhere.

## Put it on your phone

1. **Host it** with GitHub Pages: repo **Settings → Pages → Build and deployment → Source: Deploy from a branch**, pick the branch and `/ (root)`, save. After a minute the site is at `https://<your-username>.github.io/gratitude/`.
   (On a free GitHub plan, Pages needs the repo to be public. Only the app code is public; your entries never leave your phone.)
2. **Add to home screen**
   - iPhone: open the link in **Safari** → Share → **Add to Home Screen**
   - Android: open in **Chrome** → ⋮ menu → **Add to Home screen** / **Install app**
3. Always open it from the home-screen icon. On iPhone, the home-screen app keeps its own storage, separate from Safari's.

## Daily reminder

Settings (⋯) → pick a time → **Add to calendar**. This adds a repeating daily event with an alert to your calendar. To change the time, delete the event in your calendar and add a new one.

The reminder files live in `reminders/` and are generated by `node scripts/generate-reminders.mjs`.

## Backups

Your moments live only on this device, so clearing website data, deleting the app, or switching phones will lose them. Use **Settings → Export** occasionally and keep the file somewhere safe (Files, iCloud Drive, Google Drive). **Import** merges a backup back in without creating duplicates.

| --- | --- |

| `sw.js` | Service worker for offline use |
